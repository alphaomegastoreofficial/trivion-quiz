# TRIVION
### THE ULTIMATE QUIZ EXPERIENCE

**TRIVION** adalah game kuis mobile yang dikembangkan oleh Alpha Omega Store.

## Project Information

- Project Name: TRIVION
- Developer: Alpha Omega Store
- Genre: Quiz Game
- Platform: Mobile
- Language: Indonesian & English
- Game Mode: Offline
- Initial Question Bank: 100 Questions
- Repository: trivion-quiz

## Core Features

- Multiple-choice quiz (A–D)
- 25-second question timer
- Multiple knowledge categories
- Difficulty levels
- Bilingual questions and answers
- Score tracking
- Local leaderboard
- Offline gameplay

## Initial Categories

1. General Knowledge
2. Science & Technology
3. History & Culture
4. Mathematics & Logic
5. Nature & Environment
6. Riddles & Trivia

## Development Principles

- Quality over speed.
- Stable and reliable gameplay.
- Clear and accessible interface.
- Fair and enjoyable competition.
- Thorough testing before release.
